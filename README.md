# NLP Annotation and Embeddings Project

This project covers annotation and vector-based analysis of a Polish hate speech corpus.  
Part I: Dataset preparation and multi-level annotation (document + fragment level).  
Part II: Word and sentence embeddings analysis using Word2Vec, FastText, and other models.

## Folder Structure

- `data/` – raw datasets and exported annotations
- `scripts/` – Python scripts and notebooks
- `docs/` – annotation guidelines, reports, and notes
